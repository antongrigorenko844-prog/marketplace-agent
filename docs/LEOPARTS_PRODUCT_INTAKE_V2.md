# LEOPARTS Product Intake v2 — единый запрос вместо десятков команд

**Статус: проверяемая безопасная фаза инспекции.** Заказы, остатки, старые товары и реклама продолжают работать по прежнему конвейеру. Новый процесс пока не запускает массовую публикацию автоматически.

## Работа владельца
Достаточно сообщить товар, количество, согласованные цены или просьбу о расчёте, выбранные изображения, применимость и особые условия. Агент собирает ОДНУ заявку на 1–30 товаров. Без утверждения и прямых цен никакая публикация не разрешена.

## Внутренняя схема
1. Проверка SKU и дублей внутри партии, проверка фактического наличия на каждой площадке.
2. SHA-256 для каждой фотографии, запрет подмены Gen1/Gen2 и подстановки похожих рисунков.
3. Пять независимых согласованных цен Ozon / WB / Яндекс Маркет / Авито / Tilda. Старые 70/60% и «равная прибыль» не применяются к опубликованным ценам.
4. Проверка реальных обязательных категорий, характеристик, ТН ВЭД, размеров, фотографий.
5. Одна независимая транзакция по SKU и каналу, повторное чтение из кабинета — ответ «принято» не считается публикацией.
6. Другие площадки работают независимо, если одна временно не отвечает.
7. Единый статус: data/product_intake_v2/status/<batch_id>.json со статусами verified/partial/blocked и причинами.

## Активация
Новое изменение утверждённой заявки в data/product_intake_v2/requests/<batch_id>.json запускает только безопасный отчёт GitHub Actions. Никаких секретов торговых кабинетов в этом workflow нет. Включение настоящей автоматической публикации — отдельный контролируемый релиз после проверок.

## Защита текущих продаж
- Intake не перезаписывает цену действующей карточки из старого манифеста.
- Остатки действующих товаров принадлежат общему складскому синхронизатору, а не заявке на каталог.
- При отсутствии подтверждённых характеристик, категории или кода ТН ВЭД заявка блокируется на соответствующей площадке без догадок.
- Существующая Tilda-карточка не пересоздаётся с устаревшим остатком.
- Текущие xlsx master_control и avito_site_price_overrides остаются без изменений.
- Отдельная политика data/pricing_policy.json запрещает формуле Авито/Tilda самостоятельно применять цены.

## Нерешённый медиа-мост
Оригиналы, доступные только в библиотеке ChatGPT, пока нельзя автоматически передать в GitHub через текущий connector. Гарантированные источники — проверенный файл в репозитории или подтверждённый публичный HTTPS с SHA256. До отдельного медиа-моста не считать процесс полностью безручным для новых изображений.
