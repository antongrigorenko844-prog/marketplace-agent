## 2. P0 — подтверждённое одинаковое содержимое, разные цены

**Ремкомплект штока мехатроника DSG7 DQ200 0AM 0CW:** действующие ID `4285108577` (**990 ₽**) и `4220729305` (**5 890 ₽**). Владелец подтвердил, что состав комплектов одинаковый. Разница **4 900 ₽ (в 5,95 раза)** при одинаковом заголовке. Это реальная коммерческая несогласованность.

**Действие:** срочно связать оба ID с конкретным физическим SKU и его вариантом (99/101 мм, точный состав). Принять единое коммерческое решение: оставить одно объявление, согласовать одинаковую цену или ясно различить подтверждённые варианты. Нельзя автоматически менять 5 890 ₽ на 990 ₽ или наоборот: стоимость/размер варианта по доступному API не удостоверены. Оба объявления остаются нетронутыми до точной привязки.

Дополнительная похожая старая карточка `4445230063` имеет название «Ремкомплект штока DQ200 … шток + втулка» и цену **2 890 ₽**. Однозначное соответствие её состава двум указанным ID также не установлено.

## 8. Технические риски управления ценами

- **Два разных физических продукта, различающихся регистром:** `DQ500` (корпус+фильтр) и `Dq500` (только корпус); `EA888gen3` (корпус+клапан) и `Ea888gen3` (только клапан). Приведение SKU к нижнему регистру может смешать цены/остатки и вызвать дорогостоящую ошибку. Сохранять точные идентификаторы; внедрить защитный тест.
- Исторический `123014‑AF` содержит неразрывный дефис U+2011; его привязка `-av` учтена как один SKU. Не дублировать такое объявление при автоматизации.
- Отсутствие единых ID у **36 действующих ручных карточек** означает, что изменения в мастере могут их не затрагивать. Это главный риск повторения аномалий, больших и маленьких. Перед редактированием таких карточек построить проверенную таблицу «Avito ID → канонический SKU → комплектация → цена».
- Тариф автоматического пересчёта уже отключён: `data/pricing_policy.json` устанавливает `manual_prices_only`. Не запускать массовые устаревшие задания пересчёта.
- В текущем фиде 127 строк, тогда как новых инструментальных объявлений ещё два в отдельном XML. Три новых 6T30 в фиде нельзя считать опубликованными без Avito ID; это отдельная задача статуса, не аудит цен.

## 9. Управленческое решение

1. **Сделано:** 1 390 ₽ для `02E 305 045` и `DQ500`; обе активные карточки и публичный фид подтверждены. Весь остальной ассортимент и сайт — без изменений.
2. **Срочно:** карточки `4285108577` (990 ₽) и `4220729305` (5 890 ₽). Состав одинаков по словам владельца; восстановить физический SKU/вариант и согласовать новую единую цену, не угадывать её.
3. **Далее:** группа ручных старых объявлений (корпуса, фильтры, кольца, соленоиды, плиты) — решить дубли/различия исполнения и связать с мастером без потери истории.
4. **Финансовый контроль:** уточнить семь расхождений себестоимости комплектов и недостающую себестоимость новых товаров. Проверить реальные средние расходы на заказы и гарантийные случаи для дорогих мехатроников.
5. **Стратегия:** дешёвые объявления оставить действующими при текущей цене просмотра; конкуренцию между своими карточками снизить, а сайт сделать дешевле Авито **только после отдельного согласования** конкретных SKU.
