# marketplace-agent — синхронизация карточек Ozon / WB / Avito / Яндекс Маркет

Первый этап: подключиться к Ozon и Wildberries через официальные API и
посмотреть на реальные данные из ваших кабинетов. Дальше на основе этого
построим общий каталог и синхронизацию цен/остатков/заказов.

Почему через GitHub Actions, а не напрямую с компьютера — по той же причине,
что и в проекте realty-agent: сеть, из которой я работаю, не пропускает
запросы к api-seller.ozon.ru и content-api.wildberries.ru напрямую, а у
GitHub Actions доступ в интернет обычный, без ограничений.

## Настройка (если репозиторий новый)

1. Создайте приватный репозиторий на GitHub, загрузите туда все файлы этой папки
   (включая скрытую папку `.github` — на Mac показать скрытые файлы: `Cmd+Shift+.`).
2. Settings → Secrets and variables → Actions → New repository secret, добавьте:
   - `OZON_CLIENT_ID`, `OZON_API_KEY` — из кабинета Ozon (Настройки → API-ключи)
   - `WB_API_TOKEN` — из кабинета WB (Настройки → Доступ к API, Personal access token,
     категории: Контент, Цены и скидки, Маркетплейс)
3. Settings → Actions → General → Workflow permissions → выбрать
   "Read and write permissions" → Save.

## Как проверить, что ключи работают

Вкладка **Actions** → workflow **marketplace-agent** → **Run workflow** →
в списке команд выберите `test-ozon`, запустите. Затем то же самое с `test-wb`.
В логе запуска будет написано "соединение работает" или ошибка с описанием.

## Как посмотреть реальные данные из кабинетов

Так же через Run workflow, команды `fetch-ozon` и `fetch-wb` — они сохранят
списки товаров/карточек в файлы `data/ozon_products.json` и `data/wb_cards.json`
прямо в репозитории (workflow сам закоммитит их обратно). Откройте эти файлы
на GitHub, чтобы увидеть, что реально лежит в кабинетах — это нужно мне, чтобы
спроектировать общий каталог правильно, под ваши настоящие товары и категории.

## Про склад WB

Перед тем как настраивать остатки на WB, нужно узнать ID вашего склада —
команда `wb-warehouses` выведет список в лог запуска. Найдите там нужный
склад и впишите его ID в секрет `WB_WAREHOUSE_ID`.
