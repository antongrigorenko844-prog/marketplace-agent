# Картинки постов для VK и Instagram

Положите готовые макеты от дизайнера сюда:

    social/<№ поста>/1.png
    social/<№ поста>/2.png     (для каруселей — по порядку слайдов, до 10 шт.)

Номер поста — колонка «№» на листе «Контент-план» (data/content_plan.xlsx).
Форматы: png / jpg / webp. Instagram: 1080×1350 (4:5). VK: те же файлы.

Дальше всё автоматически: каждый день в 10:00 МСК публикуется самый ранний пост, у которого
наступила «Дата выхода» и есть картинки. Опубликованное записывается в data/social_state.json.
Проверить состояние: Actions → marketplace-agent-social → social-status.
