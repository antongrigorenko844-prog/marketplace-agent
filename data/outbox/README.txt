Правки слайдов LEOPARTS

Владелец может поставить правку в Telegram одним сообщением, например:

Правка 0am325025 слайд 2 Ozon
Увеличить заголовок на втором слайде.
Текст: Что входит в комплект

Для списка отправьте «Мои правки», для подсказки «Помощь по карточкам». У каждого задания есть ID и версия. Дизайнер прикладывает один файл с подписью «Сдать ID v1». Владелец отвечает «Принять ID v1» или «Вернуть ID v1» и со следующей строки пишет замечание. «Изменить ID v1» с обновлённым заданием и текстом создаёт следующую версию. Принятый файл остаётся доступен в задаче; размещение на витринах выполняется отдельно.

Для исходных изображений подпишите каждый альбом «Карточка АРТИКУЛ» или «Карточка АРТИКУЛ Авито». Бот принимает продолжения и показывает количество. Неразмеченный альбом можно привязать по коду из ответа.

Новое поручение на слайд через Git передаётся файлом data/outbox/<имя>.json:
{"card_task":{"action":"create","sku":"0am325025","slide":2,"platform":"Ozon","brief":"Увеличить заголовок второго слайда.","copy_text":"Что входит в комплект"}}

После выдачи используйте ID и текущую версию из бота. В том же файле или в отдельном JSON можно передать следующую редакцию:
{"card_task":{"action":"edit","id":"C-0123456789","version":1,"brief":"Выделить слово «комплект».","copy_text":"Что входит в комплект"}}

Каждая правка адресуется одному SKU, одной площадке и одному слайду. Старые отправленные письма сохраняют свою историю. Для обычной заметки, соцпоста и видео используйте поля to, text, images, texts и явный kind со значением note, social_post или video. Бот оставляет письмо с отсутствующим вложением в очереди. Папка и реестр общедоступны: помещайте в задание только материалы товара.
