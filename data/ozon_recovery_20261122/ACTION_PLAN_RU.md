## Что отключать / проверять в личном кабинете (нет API для этих переключателей)

1. **Товары → Ускоренный сбор отзывов** — остановить платные кампании и проверить автодобавление новых товаров. 610 ₽/последняя неделя. У некоторых карт может быть смысл оставить лишь тест, но пользователь хочет прекратить ненужные расходы.
2. **Товары → Отзывы → Сбор первых отзывов** — проверить, не запущены ли кампании, и остановить неподтверждённые. На свежей 28-дневной выборке нет списаний, но старый отчёт 17.10–16.11 содержал 2242,24 ₽ для 0am325025j. Ранее заказанные обзоры могут тарифицироваться после отмены.
3. **Подписка «Управление отзывами»** — открыть кабинет подписки (https://seller.ozon.ru/app/reviews/subscription) и отключить автопродление, если не нужна автоматизация отзывов/API. Цена ~1,3% от реализации, 5109,27 ₽ последняя неделя. ВАЖНО: прекращение подписки может лишить Seller API доступа к списку отзывов; локальный `reviews_guard.py` блокирует архивирование при неизвестном статусе отзывов (fail closed).
4. **Продвижение → Механики лояльности → Звёздные товары** — проверить отключение. 6556,83 ₽ неделя; отключать после проверки того, что программа не даёт дополнительных целевых продаж, либо тестом с контролем двух недель. Пользователь явно просил остановить утечки.
5. **Финансы → Выплаты → Изменить график выплат** — при наличии ликвидности перейти с платного гибкого на стандартный, потенциально 9644,78 ₽ за прошлую неделю. НЕ делать при угрозе кассового разрыва.
6. **Финансы → Начисления / Заказы с моих складов → детали доставки → индекс ошибок** — запросить разбивку штрафа 7295,26 ₽ за 15–21.11: отправления, причины, даты, инициатор, дата приёмки на СЦ. Клиентские отмены сами по себе не доказывают неправомерность или правомерность общего штрафа.

**Не отключать без расчёта:** «Эластичный бустинг» (32 участия), «Супербустинг 11.11» (13), «Максимальный бустинг 11.11 и Чёрная пятница» (16), его усиление (11), «Лайт бустинг 11.11» (16). Пересечения допустимы, суммы участников не складывать. Эти акции суть скидки/бустинг, а не доказанная стоимость отдельной услуги; при отключении могут упасть заказы.

## Быстрые действия для роста прибыли без увеличения бюджета

- **Доставка:** запросить маршрут 10 FBS 8–12 дней + 3 FBS 16–18 дней + 2 FBO 12–13 дней. Проверить срок доставки в карточке покупателя; предъявить в Ozon отметку приёмки на СЦ.
- **Карточки:** разобраться с 7 отменами SKU `0AM325443D`: точный номер, фото/размер/комплектация, цена, текст совместимости, срок доставки. Исправить причины «товар не подошёл».
- **Падение по артикулам (FBS, по отправленным единицам):** `podshipnik-vilki-6` 11→0 (при остатке FBO6/FBS31), `0am325025` 15→8 (FBO1/FBS14), `0am325025l` 8→1 (FBO5/FBS83), `0am325025H` 8→4 (FBO1/FBS14). Проверить ценовые изменения, показы, модерацию и участие в промо, прежде чем менять цены.
- **Товар без наличия:** `0am325025x` (FBS0) имел существенную историческую выручку. Восстанавливать остаток только после проверки физического склада.
- **FBO:** приоритетная выборочная поставка популярных малогабаритных SKU, если экономия доставки и маржа подтверждены по изделию; не переводить весь каталог без расчёта.
- **Финансы:** не повышать расходы на Директ пока нет измеряемых лидов, следить за ограничением 4 000 ₽/неделя.
- **Контроль после отключений:** сравнить полные недели по расходам этих услуг, заказанным единицам, отменам, цене доставки, доле продаж FBO.
